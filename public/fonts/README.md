# Self-hosted typefaces

Four unmodified OFL-licensed variable WOFF2 files preserve the approved Duet typography without Google Fonts requests at build or runtime.

- `InterVariable.woff2` — [rsms/inter](https://github.com/rsms/inter/blob/main/docs/font-files/InterVariable.woff2); see `LICENSE-Inter.txt`.
- `JetBrainsMono-Variable.woff2` — [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono/blob/master/fonts/webfonts/JetBrainsMono%5Bwght%5D.woff2); see `LICENSE-JetBrainsMono.txt`.
- `SourceSerif4Variable-Roman.woff2`, `SourceSerif4Variable-Italic.woff2` — [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif/tree/release/WOFF2/VAR); see `LICENSE-SourceSerif4.md`.

Loaded through `next/font/local` in `src/app/layout.tsx`. Keep copyright and license files with the fonts.
