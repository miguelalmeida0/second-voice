# Delivery Plan

## Build Order

### Phase 1: Rewrite Theater

Scope:

- live rewrite playback
- skip animation
- reduced motion fallback

Why first:

This is the highest-leverage improvement to first impression.

### Phase 2: One-Click Demo Path

Scope:

- `Surprise Me`
- curated preset library
- improved empty state copy

Why second:

This removes friction and makes the portfolio app self-demoing.

### Phase 3: Visible Craft

Scope:

- How It Works drawer
- concise system explanations
- links to case study

Why third:

This is the credibility layer once the product already feels fun.

### Phase 4: Narrative Layer

Scope:

- case study route
- screenshots and supporting copy
- metadata polish

Why fourth:

This converts a fun demo into a strong portfolio project.

## Suggested Time Budget

If executed cleanly by a senior engineer:

- Phase 1: 1 to 2 days
- Phase 2: 0.5 to 1 day
- Phase 3: 0.5 to 1 day
- Phase 4: 0.5 to 1 day

Total:

- roughly 3 to 5 focused days

## Risk Register

### Risk 1

Animation looks noisy or hard to read.

Mitigation:

- prioritize legibility over spectacle
- add `Skip animation`
- cap playback duration

### Risk 2

Surprise Me feels random instead of curated.

Mitigation:

- use preset-driven combinations
- bias toward stronger demo outputs

### Risk 3

How It Works becomes too technical and breaks the charm.

Mitigation:

- keep each section short
- use plain language
- treat it like product storytelling

### Risk 4

Case study feels detached from the product.

Mitigation:

- keep the same visual language
- link directly from the app
- show product screenshots, not just prose

## Launch Checklist

1. `Surprise Me` path works on first load
2. animated rewrite feels smooth on desktop and mobile
3. reduced motion path is correct
4. How It Works content is accurate
5. case study route is polished and linked
6. metadata and OG still work
7. app still builds successfully

## Final Review Standard

Before shipping, ask:

1. If someone sees only this project, do they believe the builder has product taste?
2. If an engineer reviews it, do they see discipline, not just styling?
3. If a recruiter clicks around for 60 seconds, do they remember it later?

If the answer is not clearly yes, keep polishing.
